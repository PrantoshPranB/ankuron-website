Get Ankuron

Mac

macOS 13 or later

  1. Unzip and move Ankuron.app to ~/Library/Input Methods (in Finder: Go › Go to Folder…, then type that path).
  2. Double-click the two Ankuron fonts and click Install.
  3. System Settings › Keyboard › Input Sources › Edit › + › Assamese › Ankuron.
  4. Switch with Ctrl+Space or the Globe key.
Ankuron isn't in the list, or macOS blocks it?

This early version isn't notarized by Apple yet, so macOS holds back the download. Open Terminal, paste this, press Return, then log out and back in:

xattr -dr com.apple.quarantine ~/Library/Input\ Methods/Ankuron.app

Windows

Windows 10 or 11, 64-bit

  1. Run Ankuron-Setup.exe; it also installs the font.
  2. A tray icon appears: red অ means on, grey means off.
  3. Toggle with Alt+Shift; right-click the icon for “Start with Windows”.
